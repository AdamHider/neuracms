# Добро пожаловать в FlatCMS

Это маленькая CMS без базы данных. Контент лежит в папке `content/`, каждый
элемент описывается набором свойств в `item.yaml`, а тело берётся из `content.md`.

- Простое ядро без тяжёлого фреймворка
- Всё есть Item: страница, товар и запись блога отличаются только полем `type`
- Модули расширяют систему через хуки и маршруты
